## 🛠️ Serviços Implementados

### 1️⃣ Amazon EC2 Auto Scaling
- **Objetivo:** Gestão dinâmica de capacidade computacional.  
- **Benefício:** Ajuste automático de instâncias EC2 conforme demanda, reduzindo custos em períodos de baixa utilização.

### 2️⃣ Amazon S3 (Simple Storage Service)
- **Objetivo:** Armazenamento escalável e econômico.  
- **Benefício:** Uso do **S3 Intelligent-Tiering** para mover arquivos pouco acessados para camadas de custo reduzido.

### 3️⃣ Amazon RDS (Relational Database Service)
- **Objetivo:** Banco de dados relacional gerenciado.  
- **Benefício:** Eliminação de manutenção manual, redução de custos operacionais e maior disponibilidade para rastreabilidade de medicamentos.
